# TaskFlow - Daily Task Manager

A responsive and user-friendly task management web application developed as a Frontend Development learning project for internship submission at Labmentix.

## Project Overview

TaskFlow is a simple web application designed to help users organize their daily activities and manage tasks efficiently.

Users can create tasks, mark them as completed, filter tasks according to their status, and delete tasks when they are no longer needed.

The application uses browser localStorage to save tasks, allowing users to retain their task list after refreshing the page.

## Project Objectives

- Practice frontend development fundamentals.
- Build a responsive user interface.
- Understand JavaScript DOM manipulation.
- Implement interactive website functionality.
- Learn how to store data using browser localStorage.
- Practice organizing and publishing code using GitHub.

## Features

- Add new tasks.
- Mark tasks as completed.
- Delete individual tasks.
- Filter tasks by All, Active, and Completed.
- Clear all completed tasks.
- Display total, completed, and remaining task counts.
- Automatically display the current date.
- Save tasks using browser localStorage.
- Responsive layout for desktop and mobile devices.

## How to Run the Project

1. Open the GitHub repository.
2. Download the project files or clone the repository.
3. Keep all four files in the same folder.
4. Open index.html in a modern web browser.
5. Start adding and managing your tasks.

No additional software or package installation is required.

## How the Application Works

### 1. HTML
HTML provides the structure of the application, including the task input form, summary cards, filter buttons, and task list.

### 2. CSS
CSS controls the visual appearance, layout, colors, typography, and responsive behavior.

### 3. JavaScript
JavaScript handles task creation, completion, deletion, filtering, and updates to the task statistics.

### 4. localStorage
The browser's localStorage API stores tasks as JSON data so that the task list remains available after refreshing the page in the same browser.
